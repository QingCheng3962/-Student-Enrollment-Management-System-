# 学生学籍管理系统 (Student Enrollment Management System)

一款基于 Python + Tkinter 开发的桌面端「学生学籍管理系统」，提供学生信息检索、照片管理、档案打印、数据导入与批量导出等完整功能。

> 本仓库仅包含源代码（`student.py`）。由于学生照片与学籍信息属于个人隐私数据，**默认不随仓库发布**。
> 如需运行完整功能，请按下文说明在本地准备 `_internal` 数据目录。

## 功能特性

- **学生列表页**
  - 支持按「姓名 / 学籍号 / 身份证号」关键词搜索，一键显示全部 / 清空
  - 列表按列排序、隔行变色、支持滚动浏览
- **学生详情页**
  - 展示学生详细信息（姓名、学籍号、身份证号等，字段来自 Excel 数据表）
  - 照片多张浏览（上一张 / 下一张），双击查看大图
  - 照片管理：增加照片、删除照片（上限 20 张/人）
- **打印功能**
  - 选择照片尺寸后生成可打印页面并在浏览器中打开
  - 可打印单个学生档案或随机抽取学生
- **随机展示**：随机抽取学生并展示其照片与信息
- **数据管理**
  - 导入 Excel 表格并合并去重
  - 手动修正（补录）学生信息
  - 单个 / 批量导出学生档案为 ZIP
  - 一键重载、打开数据文件夹
- 统一配色与圆角卡片风格界面，DPI 自适应

## 环境要求

- Python 3.8+
- 依赖库：`pandas`、`openpyxl`、`Pillow`（Tkinter 为 Python 标准库）

```bash
pip install pandas openpyxl Pillow
```

## 数据目录结构

程序运行时以「脚本所在目录」为基准定位数据（若打包为 exe 则以解压目录为基准）：

```
项目根目录/
├── student.py                 # 主程序
└── _internal/                 # 数据目录（默认不随仓库发布）
    ├── pic/                   # 学生照片（文件名需含 姓名/学籍号/身份证号，供自动匹配）
    └── studentinfo/
        └── students_data.xlsx # 学生信息主数据表
```

## 运行

```bash
python student.py
```
